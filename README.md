# Capex Lens

Track the divergence between AI infrastructure momentum and hyperscaler monetization.

Capex Lens is an evidence-first dashboard for observing the AI infrastructure investment cycle. The MVP compares supply-chain momentum with hyperscaler CAPEX monetization and classifies the market into four regimes: CAPEX Expansion, Healthy Reset, Bubble Divergence, and CAPEX Downturn.

See `PLAN.md` for the product and implementation plan.
